# PLY Web Player

نسخة ويب مستقلة لمشغّل PLY، من غير اعتماد على مكتبات أو خادم خلفي.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث، أو انشر محتويات مجلد `web` على أي استضافة صفحات ثابتة.

## الاستخدام

- اختر ملفات MP3 أو MP4 أو اسحبها إلى الصفحة.
- اضغط علامة `+` بجانب «قوائم التشغيل» لاختيار ملف M3U أو M3U8.
- روابط HTTP وHTTPS الموجودة في قوائم التشغيل تعمل حسب دعم المتصفح لصيغة الوسائط وسياسة CORS الخاصة بمصدرها.
- قوائم M3U ذات المسارات المحلية النسبية لا تستطيع صفحات الويب فتح ملفاتها تلقائيًا؛ اختر ملفات الوسائط نفسها من الجهاز لتشغيلها.

تُشغّل الملفات المحلية داخل المتصفح فقط، ولا تُرفع إلى خادم.
